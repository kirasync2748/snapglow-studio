# Changelog

## 0.1.0

- Initial offline screenshot studio with all 242 bundled language grammars and bundled font.
- Backgrounds, custom colors, transparent canvas, themes, window styles, line controls, and local presets.
- PNG, browser SVG, and image clipboard output with size limits.
- Anime artwork used for the extension, studio header, and tab icons.
- Explicit studio colors keep headings, controls, and presets readable with light host themes.
- Save As chooses the destination and remembers the folder for the current session.
